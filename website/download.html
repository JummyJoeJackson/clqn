~/clqn Documentation

Download clqn

One CLI for you and your agents. Includes the local MCP server for Codex and Claude Code.

npm

Install with npm (Node.js 22.12+):

npm install -g clqn-cli
clqn --help

Code workflows also need Git and an authenticated GitHub CLI (gh).

Homebrew alternative

Install from our tap. Homebrew manages Node.js for you.

brew tap rli8145/clqn https://github.com/rli8145/clqn
brew install clqn

Update with brew upgrade clqn.

Build from source

Available now. Extract the ZIP, then run these commands with Node.js 22.12+ and npm 10+.

Download source (.zip) 
npm ci
npm run build
npm link --workspace @clqn/cli
clqn --help
